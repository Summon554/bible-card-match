# Bible Memory Match

Create a memory matching card game web app called "Bible Memory Match" 

using React and Tailwind CSS.



Features:

- Grid of face-down cards (start with 4x4 = 16 cards / 8 pairs)

- Card pairs based on these Bible characters (use simple icon/emoji or 

  name text on each card): Moses, Noah, David, Abraham, Joseph, Daniel, 

  Esther, Samson

- Click two cards to flip them; if they match, they stay face-up; 

  if not, they flip back after 1 second

- Track number of moves and time elapsed

- Show a "You Win!" screen with total moves/time when all pairs are found

- "New Game" / restart button that reshuffles cards

- Clean, friendly design with soft colors, rounded cards, and a nice 

  flip animation

- Mobile-responsive layout

- Optional: difficulty selector (4x4, 6x4, 6x6 grid sizes) that adds 

  more characters (e.g. Ruth, Solomon, Elijah, Deborah for bigger grids)
